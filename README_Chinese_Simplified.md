文件校验器是一款简单易用的批量文件校验工具，支持MD5、SHA-1、SHA-256、SHA3系列、CRC-32等算法。

目前我们为以下操作系统提供安装程序：
- Windows x64（Windows 10（10.0.10240.16384）及以上版本）
- Windows Arm64（仅在Windows 11 25H2上测试过）
- macOS（仅 Apple 芯片，仅在 macOS 26 Tahoe 上测试过）

其他平台可尝试下载源代码并使用。

## 软件语言
